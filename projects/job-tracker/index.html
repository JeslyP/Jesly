How it works

Built in plain HTML, CSS and JavaScript with no libraries. Data is stored in the browser with localStorage, so the page works offline and nothing is sent to a server.
  • Each record keeps its current status and the furthest stage it reached, which drives the funnel and conversion rates.
  • Follow-ups on or before today are flagged and sorted to the top.
  • Export CSV gives a clean table for analysis in SQL, Python, R or Power BI.
