Robotics

University of York · Jan 2026

Autonomous multi-robot barrel collection

Multi-robot system for TurtleBot3 Waffle Pi in Gazebo, built in Python and ROS2 inside Docker. An 8-state finite state machine coordinates patrol, target selection, pickup, delivery, and decontamination, using Nav2 for navigation, LiDAR obstacle sectoring, and proportional visual servoing. Validated across five 3-hour test scenarios with 90–100% detection accuracy.
